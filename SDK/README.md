# 死神 vs 火影竞技版 · AI 参赛开发包

本包适配 Windows 版《死神 vs 火影 竞技版》3.8.8.5。参赛程序通过标准输入读取裁判的数据，通过标准输出返回选角和战斗操作。可以先用随包的两支队伍开赛，观察各自如何选人、移动和出招。

## 用自己的 AI 参赛

1. 复制 `Examples/Blaze` 或 `Examples/Tide` 文件夹，给副本起一个新名字。每个样例可以独立运行。
2. 把实际参赛的 AI 模型显示名填进 `entrant.json` 的 `name`，并设置队色。竞技场会在角色头顶和比分栏显示这个名字。修改 `bot.py` 的选角和战斗函数，保留逐行读取、逐行回复、立即刷新输出的主循环。发布版裁判自带 Python 运行时，两个样例仅使用标准库。
3. 在比赛管理器中选择自己的文件夹。可选「玩家对 AI（单局）」让真人用 P1 键位测试，也可选「选手对游戏 CPU（单局）」练习。正式比赛用两个选手文件夹，由主持人指定地图。
4. 提交时把 `entrant.json` 和脚本或 EXE 一起放在文件夹内。接收方解压后选择这个文件夹即可。只运行来源可信的选手包，选手程序以当前 Windows 用户身份执行。

选角按裁判当局名单执行。双方锁定选择后，战斗 `frame` 可通过 `lineups` 和 `opponent` 提供双方阵容顺序、辅助和对手当前角色。赛后可用回放旁的 `*.bvnreport.json` 辅助复盘。

- [比赛规则.md](比赛规则.md) 说明选角、座位轮换、计分和比赛限制。
- [协议.md](协议.md) 说明裁判消息、按键组合、按住和松键。
- [角色与辅助图鉴.html](角色与辅助图鉴.html) 可直接用浏览器打开并离线搜索，收录参考安装裁判名单中的 55 个角色和 59 个辅助。支持搜索名称、ID、招式和效果。供 AI 读取的相同资料见 [角色与辅助数据.json](角色与辅助数据.json)。实际选角以本局 `draft` 名单为准。
- [裁判自动化.md](裁判自动化.md) 说明如何查询地图、启动练习和比赛、检查进度或停止比赛。
- [赛后复盘.md](赛后复盘.md) 说明如何查看回放和解读赛后报告。

## 参赛清单

```json
{"name":"北风","color":"#3277CA","protocol":1,"engine":"bundled-python","script":"bot.py"}
```

队名使用 1 至 32 个可显示字符，队色用六位十六进制表示。脚本可以引用同文件夹的 Python 模块。若策略依赖额外的解释器、框架或动态库，可自行打包成 Windows EXE，再用以下清单。入口路径相对于清单目录。

```json
{"name":"秋岚","color":"#7872AC","protocol":1,"engine":"executable","executable":"runner.exe","args":[]}
```

选手进程的工作目录是自己的参赛目录。请将需要保留的数据存入自己的文件夹。标准输出专用于协议，并且每次回复必须刷新。公开发行前建议关闭调试输出。裁判会在每局结束时关闭自己启动的选手进程。
