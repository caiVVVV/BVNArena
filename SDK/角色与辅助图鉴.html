按键记法、资料来源与适用范围

W/S 为 up/down，J 为 attack，K 为 jump，L 为 dash，U 为 skill，I 为 super，O 为 assist。SJ 即 ["down","attack"]。KJ 通常指起跳后在空中使用普攻。具体操作参见 SDK 协议。

名称与机制出自本版游戏的 lang/zh-CN.json。候选范围来自实际的 AIArena/data/catalog.json，招式补丁依本版安装内 readme 的 3.8.8 及后续补丁资料。条目中明确标注版本的历史留档可作为练习线索。辅助等效回满时间来自对应补丁的默认设置，实际可受比赛规则影响。游戏官方竞技版入口

「影响己方」筛选含主角色自身扣血、无差别命中以及双方都可能受到的移动或控制效果。各条目会说明已确认的范围。用于开发和赛前训练时，可结合对应版本的资料和实机观测。正式对局按裁判当局的数据决策。
