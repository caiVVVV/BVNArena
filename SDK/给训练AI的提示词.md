# 可复制给编程助手的任务

请为 Windows 版《死神 vs 火影 竞技版》3.8.8.5 的本地 AI 比赛编写一支选手。先阅读同目录的 [协议.md](协议.md)、[比赛规则.md](比赛规则.md)、[角色与辅助图鉴.html](角色与辅助图鉴.html) 及 `Examples` 下任意一个样例。可直接读取 [角色与辅助数据.json](角色与辅助数据.json) 查询角色名称、可选 ID 和资料来源。交付一个独立文件夹，包含 `entrant.json` 和可以直接运行的 `bot.py`，通过发布版自带的 Python 和标准库运行。

请把实际参赛的 AI 模型显示名填进 `entrant.json` 的 `name`，例如 `"name": "DeepSeek"`。竞技场会用它作为角色头顶和比分栏里的名字。知道具体型号时可以填完整型号，最多 32 个可显示字符。如果你无法确认型号，请填写主持人提供的显示名，再设置六位十六进制队色。

每局根据 `draft` 消息中的真实角色和辅助 ID 盲选，按 `teamSize` 返回不重复且有出场顺序的 `roster` 和一个 `assist`。对缺少偏好角色的名单提供有效回退。双方锁定选角后，战斗 `frame` 可提供 `lineups` 和 `opponent`，据此读取已公开的阵容顺序、辅助和当前出场角色。

开发和练习时可以上网查攻略、官方更新和比赛录像，记录适用版本，并用当前游戏的练习和回放验证。把已验证信息用于选角和战术设计，包括招式触发条件、气量、耐力、辅助能量、自伤及可能波及己方的辅助。请把资料缺失的效果保留为未知。正式比赛运行时，根据裁判消息和本地策略决策。遵守比赛规则，通过协议发按键，保持程序可以离线完成整局。

战斗时按 `seat` 找到己方。根据双方距离、相对移动、角色状态、资源和近期动作选择移动、位移、防御、普攻、技能、必杀、空中行动和辅助。按 [协议的按键表](协议.md#按键与组合) 组合操作，区分持续按住与重新点按，处理角色更换、帧号跳变、可选字段缺失及招式失败。可以利用出招前后的公开观测判断命中、受击、位移和资源变化，并在练习中校准策略。交付时分别说明哪些动作做过实机验证、哪些仅通过离线测试。

程序持续逐行读 UTF-8 JSON，回传原 requestId，战斗时同时回传原 tick，每行回复后立即 flush。计算须在默认 40 毫秒行动窗口内完成。请用标准输入样本自测选角、左右任意席位、缺失可选字段和长时间对局，并简述策略与已验证的情况。

主持人允许实机训练时，按 [裁判自动化.md](裁判自动化.md) 调用 `BVNArena.exe --referee-api`。先用 `list_maps` 确认地图 ID，再以 `teamB: null` 发起 CPU 练习。用任务目录中的 `status.json` 跟踪进度，结束后以 `run` 响应中的 `result` 核对胜负与回放。按 [赛后复盘.md](赛后复盘.md) 结合回放旁的 `*.bvnreport.json` 与保存的裁判观测来复盘。
