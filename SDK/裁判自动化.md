# 本地裁判自动化接口

用已安装的 `AIArena/BVNArena.exe` 读取一个 JSON 请求并写回一个 JSON 响应。接口供训练脚本和比赛主持脚本调用。启动比赛时会打开原游戏窗口。请保持游戏窗口打开，避免最小化和手动操作。选手仍按 [协议.md](协议.md) 通过自己的标准输入和输出通信。

要亲自对阵 AI 选手，请在比赛端的「比赛模式」中选择「玩家对 AI（单局）」。可以单独调整地图、三名角色的出场顺序和援助。游戏打开后使用游戏设置中的 P1 键位操作。

```text
BVNArena.exe --referee-api REQUEST.json RESPONSE.json
```

请求使用 UTF-8，允许 BOM。请求字段中的相对路径以请求文件所在目录为基准。响应路径使用调用进程的工作目录作为相对路径的基准。请指定可写的 `.json` 响应路径，例如 `run-response.json`，并与请求路径错开。文件名 `status.json` 保留给任务状态。

## 查询地图

```json
{"op":"list_maps"}
```

响应的 `maps` 数组包含各地图的 `id` 和 `name`。开赛时填写 `id`。省略 `gameDir` 时使用 `BVNArena.exe` 所在的游戏副本。也可通过 `gameDir` 选择其他已安装竞技场的游戏副本。查询地图只读取游戏文件。

## 开始比赛

```json
{
  "op": "run",
  "teamA": "my-team",
  "teamB": null,
  "map": "random",
  "jobDir": "jobs/practice-001",
  "dataDir": "data/practice"
}
```

| 字段 | 含义 |
| --- | --- |
| `teamA` | 选手文件夹或清单文件路径 |
| `teamB` | 第二位选手的路径。显式填 `null` 可与游戏 CPU 打一局 |
| `map` | 地图 ID，或 `random` 随机选图 |
| `jobDir` | 每次运行指定一个尚未创建的任务目录 |
| `gameDir` | 可选。默认为比赛端所在的游戏副本 |
| `dataDir` | 可选。用于系列赛档案和回放，默认为游戏目录内的 `AIArena/data` |
| `skipCutIn` | 可选。设为 `true` 启用跳过大招特写的实验设置，默认 `false` |

`run` 进程持续到整场比赛结束、停止或失败，并在退出前写入响应。完成时的 `result` 包含 `seriesId`、`score`、`practice`、`winner`、`recordings` 和 `ledger`。新版的 `result.reports` 列出成功导出的赛后复盘路径。停止或失败后的正式比赛可用新的 `jobDir`，沿用同一 `gameDir`、`dataDir`、选手版本、地图配置和 `skipCutIn` 续赛。CPU 练习每次重新开局。

## 查询进度与请求停止

运行中的任务会原子更新 `jobDir/status.json`。可直接读取该文件中的 `state`、`message`、`startedAt` 和 `updatedAt`，也可用单独的 JSON 请求查询状态。

```json
{"op":"status","jobDir":"jobs/practice-001"}
```

```json
{"op":"stop","jobDir":"jobs/practice-001"}
```

`stop` 响应会显示 `stopRequested`。请等待原 `run` 进程结束，再读取最终结果。若比赛已结束，`stop` 会返回当前终态。最终状态为 `completed`、`stopped` 或 `failed`。如果比赛进程异常退出，结合进程退出和最终响应判断任务结果。此时 `status.json` 可能仍显示最后写入的进度。

响应都有 `ok` 和 `op`。失败响应提供 `error.code` 和 `error.message`。退出码 `0` 表示调用成功，`1` 表示请求或运行失败，`2` 表示 `run` 已停止。对已失败的任务执行 `status`，查询仍可成功，任务结果以 `state` 为准。

## 从 PowerShell 启动

先把示例请求分别保存为独立文件。以下示例从后台启动一场练习，然后等待它的最终响应。需要同时查询进度或停止时，可在同一终端中先查看任务目录，或用另一条 `Start-Process` 调用传入查询或停止请求。

```powershell
$arena = 'D:\BVN\AIArena\BVNArena.exe'
$process = Start-Process -FilePath $arena -PassThru -WindowStyle Hidden -ArgumentList @(
    '--referee-api'
    '"D:\BVN training\run.json"'
    '"D:\BVN training\run-response.json"'
)
$process.WaitForExit()
$process.ExitCode
Get-Content -LiteralPath 'D:\BVN training\run-response.json' -Raw -Encoding UTF8 | ConvertFrom-Json
```

查询地图、查询状态和请求停止时，可为 `Start-Process` 加上 `-Wait`，等响应写完再读取。

## 从 Python 启动

```python
import json
from pathlib import Path
import subprocess

arena = Path(r"D:\BVN\AIArena\BVNArena.exe")
request = Path(r"D:\BVN training\maps.json")
response = request.with_name("maps-response.json")
request.write_text(json.dumps({"op": "list_maps"}), encoding="utf-8")

call = subprocess.run([arena, "--referee-api", request, response])
reply = json.loads(response.read_text(encoding="utf-8"))
print(call.returncode, reply)
```

比赛请求可用相同的参数启动。需要在比赛过程中继续操作时，用 `subprocess.Popen` 启动 `run`，然后读取任务状态或发出单独的停止请求，再用 `wait()` 等待结束。
